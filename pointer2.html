字符数组与字符指针

下面两列的 str 分别属于两个独立的程序。字符指针是保存地址的变量；字符数组拥有自己的字符存储空间，数组名在多数表达式中转换为首元素地址，但数组本身不是指针变量。

改变地址与修改字符，是两件不同的事
比较项目字符指针
char *str = "hello";		字符数组
char str[6] = "hello";
建立的对象一个指针变量，保存字符串字面量的地址6 个字符的数组，保存 hello 和结尾的空字符副本
str[0] = 'H';不能这样修改字面量：属于未定义行为，可能运行时崩溃，不一定编译报错合法，数组中的内容变为 Hello
str = NULL;合法，指针改为空；之后不能再解引用或当作字符串读取不合法，数组不能整体赋值，编译器会诊断错误
str = "world";合法，改指向另一个字面量，原字面量未改变不合法；数组初始化与后续赋值是不同的操作
sizeof(str)指针变量的大小，取决于实现，不是字符串长度整个数组的大小，此例为 6 字节
初始化后 strlen(str)5，不计结尾的空字符5，不计结尾的空字符

char str[N] = "hello"; 要作为字符串使用，N 至少为 6，以容纳结尾的 '\0'。数组在其生命周期内不能通过给数组名赋值来改变位置；可以修改其中的元素。

字符指针能否用于修改字符，还取决于它当前指向哪里：char *p = buffer; 若指向可修改的字符数组，p[0] = 'H'; 就是合法的。不能把“字符串字面量不能修改”推广成“字符指针都不能修改字符”。

变量与参数

  • 实参表达式的值被复制给形参。指针形参能通过 *p 改对象，但 p = ... 只改形参；通过 int **pp 和 *pp = ... 才能修改调用者的指针对象。
  • 数组形参 int a[] 会调整为 int *a，因此应另传长度。二维数组的行指针 int (*p)[3] 与 int **p 不是同一种类型。

栈、堆与存储期

  • 普通局部变量和形参通常借助调用栈实现，其自动存储期随所属作用域结束。调用栈是教学模型，C 标准不要求具体物理布局。不能返回局部自动对象的地址供调用者使用。
  • malloc 分配的对象通常称为“堆内存”，没有自动初始化，也不会随申请它的函数返回而释放。申请失败返回 NULL；成功后应初始化、使用，并由明确的持有者调用一次 free。
  • 局部指针变量与它指向的堆对象是两个对象，生命周期可以不同。free(p) 释放对象，不会替你把 p 或其他别名置 NULL；释放后它们不能再用于访问该对象。p = NULL 也不会修复其他别名。
  • 字符串字面量和静态存储期对象持续整个程序运行。不能对字面量、普通局部数组或局部变量调用 free。演示地址经过归一化，仅用于比较对象与指向。
