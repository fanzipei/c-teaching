指针2

进一步区分对象、地址、访问权限和生命周期。右侧的指针图、内存和调用栈会随每一步同步变化，可后退比较函数调用前后和 free 前后的状态。

字符数组与字符指针

  • char a[] = "cat"; 建立包含 'c'、'a'、't'、'\0' 的可修改数组；sizeof(a) 是 4，strlen(a) 是 3。数组不能整体赋值。
  • const char *p = "cat"; 建立指针，指向有静态存储期的字符串字面量。p 可以重新赋值；修改字面量是未定义行为。在 C 中即使用 char *p 接收字面量，也不能修改它。
  • 指针可以指向字符数组、字面量或动态分配的字符缓冲区。是否能写取决于对象及访问类型，不能仅凭“字符指针”判断。sizeof(p) 是指针大小，取决于实现，不能当作字符串长度。

const、变量与参数

  • const int limit = 3; 声明只读对象，它仍是有类型和生命周期的对象；C 中它通常不能代替要求整数常量表达式的场合。const 不意味着对象一定放在某个只读内存区域。
  • const char *p 限制通过 p 改字符；char *const p 限制 p 改指向；const char *const p 同时限制两者。不能强行去掉 const 来修改原本就定义为 const 的对象。
  • 实参表达式的值被复制给形参。指针形参能通过 *p 改对象，但 p = ... 只改形参；通过 int **pp 和 *pp = ... 才能修改调用者的指针对象。
  • 数组形参 int a[] 会调整为 int *a，因此应另传长度。二维数组的行指针 int (*p)[3] 与 int **p 不是同一种类型。

栈、堆与存储期

  • 普通局部变量和形参通常借助调用栈实现，其自动存储期随所属作用域结束。调用栈是教学模型，C 标准不要求具体物理布局。不能返回局部自动对象的地址供调用者使用。
  • malloc 分配的对象通常称为“堆内存”，没有自动初始化，也不会随申请它的函数返回而释放。申请失败返回 NULL；成功后应初始化、使用，并由明确的持有者调用一次 free。
  • 局部指针变量与它指向的堆对象是两个对象，生命周期可以不同。free(p) 释放对象，不会替你把 p 或其他别名置 NULL；释放后它们不能再用于访问该对象。p = NULL 也不会修复其他别名。
  • 字符串字面量和静态存储期对象持续整个程序运行。不能对字面量、普通局部数组或局部变量调用 free。演示地址经过归一化，仅用于比较对象与指向。
