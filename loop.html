循环语句

循环语句让代码能够重复执行。核心知识点：

  • while：先判断条件，再执行循环体，可能一次都不执行
  • for：适合已知循环次数，语法紧凑（初始化; 条件; 更新）。本页示例采用经典 C 写法：先声明 int i;，再写 for (i = 0; ...)；而 for (int i = 0; ...) 这种直接在循环头里声明变量的写法是 C99 之后才支持的，旧版本编译器并不接受
  • do-while：先执行一次循环体，再判断条件，至少执行一次
  • break 立即跳出整个循环；continue 跳过本次剩余代码
  • 循环变量通常用 i, j, k，注意避免死循环（条件永远为真）
  • 嵌套循环：外层循环一次，内层循环完整执行一轮
  • 多层循环中 break / continue 只作用于当前所在层，不会影响外层循环
  • 想一次性跳出多层循环：用 flag 标志变量配合循环条件（&& !found），一层一层退出

下面每个示例的程序流程图会同步高亮当前执行位置： 当前节点 走过的路径 条件为真 条件为假 / 退出循环 回到循环条件

条件为真：执行循环体后回到判断；条件为假：向下退出循环
while 与 do-while：判断和执行的先后顺序不同
continue：从循环体中途直接回到判断，分界线以下的本轮剩余部分被跳过；break：直接跳出整个循环
