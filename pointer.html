指针

指针是C语言的灵魂，它存储的是内存地址而非数据本身。核心知识点：

  • int *p; 声明指向 int 的指针；&a 取地址；*p 解引用
  • 指针让函数能够修改外部变量（传递地址而非值）
  • 指针与数组关系密切：数组名本质是指向首元素的常量指针
  • 指针运算：p+1 移动的是一个元素的大小，不是 1 个字节
  • 指针可以指向指针，形成多级指针（如 int **pp;）
  • 小心空指针和野指针：解引用前必须确保指向有效内存
  • 动态内存：malloc 在堆上申请内存（需 #include <stdlib.h>），用完必须 free 归还，否则内存泄漏；free 后应立刻把指针置为 NULL
指针存的是地址：p 的内容 0x1000 正是 x 的「门牌号」
