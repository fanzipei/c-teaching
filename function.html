函数

函数是C程序的基本模块，用于封装可复用的代码。核心知识点：

  • 函数定义：返回类型 函数名(参数列表) { 函数体 }
  • 值传递：C函数参数默认按值传递，形参的修改不影响实参
  • 返回值：用 return 带回结果；void 表示不返回
  • 局部变量：在函数内声明，函数结束时销毁（存于栈上）
  • 递归：函数调用自身，必须有终止条件否则死循环
  • 函数必须先声明或定义后，才能被调用
一次调用：main 把参数 3 传给 f(x)，f 用 return 带回结果 9
值传递：swap 改的只是 x 的副本，main 的 x 仍是 3——交换失败
递归：fact(3) 逐层调用到 fact(1) 触底，再逐层返回 1、2、6
