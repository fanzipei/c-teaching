条件语句

条件语句让程序能够根据条件选择不同的执行路径。核心知识点：

  • if 单独判断；if-else 二选一；if-else if-else 多分支
  • 条件表达式结果为0即假，非0即真
  • == 是相等判断，= 是赋值，初学者极易混淆
  • switch 适合多值等值判断，配合 break 使用
  • 短路求值：&& 左假则右不算；|| 左真则右不算
  • 三目运算符 ? : 是 if-else 的简洁写法

漏写 break 会从匹配的 case 一路穿透向下执行；有 break 则立即跳出
&& 左边为假则右边不算：结果直接为 0（假）
