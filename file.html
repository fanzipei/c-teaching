文件操作

文件操作让程序把数据保存到文件，也能从文件读回数据。核心知识点：

  • 包含 <stdio.h>，用 FILE *fp 保存文件流指针。
  • fopen("文件名", "模式") 打开文件，失败时返回 NULL，使用前先检查。
  • r 只读，要求文件已存在；w 写入，创建或清空文件；a 追加，创建或保留原内容并在末尾写入。
  • fputs 写字符串，fgetc 读字符；用 int 接收 fgetc 的返回值，读取结束或出错时返回 EOF。
  • fprintf / fscanf 格式化读写；fscanf 返回成功赋值的项数，读取整数时需要传入变量地址。
  • 使用完调用 fclose(fp) 关闭文件。相对文件名位于程序的当前工作目录。
