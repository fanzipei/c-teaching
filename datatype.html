数据类型与赋值语句

数据类型与输入输出是C语言编程的基石：

  • 基本类型：int（整数）、float（单精度浮点）、double（双精度浮点）、char（字符）；sizeof 可查看类型占用的字节数
  • printf 格式化输出：常用 %d（int）、%f（float/double）、%c（char）、%s（字符串）
  • scanf 格式化输入：变量前必须加 & 取地址符（数组名除外）；用返回值判断成功读取了几项
  • 转义字符：\n（换行）、\t（制表符）、\\（反斜杠）、\"（双引号）
  • 常量：#define PI 3.14（宏定义，编译时替换）
宽度按字节数成比例：double(8) = 2 个 int(4) = 8 个 char(1)

赋值语句把值存入变量，是最基础的语句：

  • C 是强类型语言：变量必须先声明类型再使用；基本形式 变量 = 表达式;
  • 类型转换：自动隐式转换（小范围→大范围）与强制类型转换 (type)expr；注意整数除法会丢弃小数部分
  • 复合赋值：+= -= *= /= %= 让代码更简洁
  • 自增/自减：i++（先用后加）与 ++i（先加后用）区别重大
  • 赋值表达式本身有值，因此 a = b = c = 5; 从右向左执行
赋值 = 把右边的值放进左边变量的「盒子」
printf 把 %d、%.1f 等占位符按顺序替换成变量的值
10/3 是整数除法得 3；先转 double 再除才得 3.33
